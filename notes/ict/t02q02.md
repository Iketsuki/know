## Answer Key & Explanations

### Question 3 (SQL)

* **(a)** `SELECT PNAME, PRICE FROM PRODUCT WHERE CATEGORY = 'EL' AND PRICE BETWEEN 100 AND 500;`
* **Explanation:** Uses `AND` to combine the category filter with a range filter.


* **(b)** `SELECT PID, PNAME FROM PRODUCT WHERE SUPP_EMAIL LIKE '%@gmail.com';`
* **Explanation:** The `%` wildcard matches any characters before the specific string.


* **(c)** `SELECT SUM(PRICE * STOCK) FROM PRODUCT WHERE CATEGORY = 'FD';`
* **Explanation:** SQL allows arithmetic expressions inside aggregate functions like `SUM`.


* **(d)** `SELECT CATEGORY, AVG(PRICE) FROM PRODUCT GROUP BY CATEGORY HAVING AVG(PRICE) > 50;`
* **Explanation:** `GROUP BY` organizes the data by category so `AVG` can calculate per group; `HAVING` filters the group results.

## Answer Key & Explanations

### (a) Primary Key

* **Answer**: `EMP_ID`.  Not Null, Unique.


* **Explanation**: Its purpose is to uniquely identify each record in the table and ensure no two employees have the same ID.

### (b) SQL Output

* **Answer**: 2 
* 
**Explanation**: These are the only employees who worked fewer than 40 hours AND had a late count greater than 0. ---> `Ivy Cheung`, `Ada Wong`.



### (c) Spreadsheet and Data Logic

* **i) Formula**: `=IF(AND(C2 >= $C$101, D2 = $D$101), 500, 0)`
* **Explanation**: Absolute addressing (`$`) is required for `C101` and `D101` so that the reference to the target values remains fixed when the formula is copied down to other rows.


* **ii) Data Type Error**: A **Data Type Mismatch** error will occur, or the system will reject the input because "Forty" is text and the field requires a number.
* **iii) Reason**: Names are not necessarily **unique** (two employees could have the same name) and names are more likely to change over time compared to a unique ID.
