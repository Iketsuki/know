Question 2: The List Replacement Trap

Look closely at Version A vs Version B. Does list = ... work the same as list[0] = ...?

items_a = ["Milk"]
items_b = ["Bread"]

def version_a(my_list):
    my_list[0] = "Eggs" # Changing an item

def version_b(my_list):
    my_list = ["Juice", "Water"] # Replacing the whole list

version_a(items_a)
version_b(items_b)

print("Q2 A:", items_a)
print("Q2 B:", items_b)

Output Q2: A: __________ B: __________

Question 3: The "Multiple Bridge" Challenge

Can you trace the value of x and y through two different functions?

x = 10
y = [10]

def boost_value(val):
    val = val + 90

def boost_list(lst):
    global x
    x = 50 
    lst[0] = lst[0] + 90

boost_value(x)
boost_list(y)

print("Q3 x:", x)
print("Q3 y:", y)

Output Q3: x: __________ y: __________

Quick Summary for your Notes:

  • Numbers & Strings: Are "Immutable" (Cannot be changed by a function unless you use global).
  • Lists: Are "Mutable" (A function can change an item inside list[0], but it cannot replace the whole list list = [...] without global). Hint If you see list[index] = ..., the change usually "sticks" to the outside world. If you see variable = ..., it usually stays "secret" inside the function unless the word global is there!
